# Snap Box

אתר תדמית לעמדות הצילום של Snap Box, עם מודל תלת-ממדי חי של עמדת ה־Snap Box, שאלות נפוצות, ביקורות (Firebase) ומצב "נסו אותי" עם מצלמה.

- `index.html`: האתר (עברית, RTL)
- `assets/js/booth3d.js`: סצנת ה־3D (Three.js): העמדה, תאורת הטבעת, קשת פרחים, עשבי פמפס, שטיח ג׳וט ורצפת אבן טבעית. המצלמה זזה בין הסקשנים לפי הגלילה.
- `assets/js/main.js`: אנימציות, טופס שנפתח בוואטסאפ, ביקורות, נגישות, ומצב "נסו אותי": מצלמה, סטריפ 2×6 או מגנט להורדה ושיתוף
- `assets/vendor/three`: ספריית Three.js מקומית (בלי תלות ב־CDN)

להרצה מקומית צריך שרת סטטי, כי מודולי ES לא נטענים מ־`file://`:

```
npx http-server .
```

קבצי הגלריה (התמונות והסרטונים `photo_*.jpg`, `document_*.mp4`) וקבצי המדיניות (`terms.html`, `privacy.html` וכו') צריכים להיות בתיקייה הראשית של האתר. פריטי גלריה שחסרים פשוט לא מוצגים.
