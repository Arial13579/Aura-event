# AURA event

אתר תדמית לעמדות הצילום של AURA event, עם מודל תלת-ממדי חי של עמדת ה־Snap Box.

- `index.html`: האתר (עברית, RTL)
- `assets/js/booth3d.js`: סצנת ה־3D (Three.js): העמדה, תאורת הטבעת, עמודי זהב, חבלי קטיפה, שטיח אדום ורצפת שיש משקפת. המצלמה זזה בין הסקשנים לפי הגלילה.
- `assets/js/main.js`: אנימציות, טפסים (Formspree), וואטסאפ, ומצב "נסו בעצמכם" עם מצלמת רשת ופולארויד להורדה
- `assets/vendor/three`: ספריית Three.js מקומית (בלי תלות ב־CDN)

להרצה מקומית צריך שרת סטטי, כי מודולי ES לא נטענים מ־`file://`:

```
npx http-server .
```
