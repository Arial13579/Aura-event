# תמונות האתר

יש להעלות לתיקייה הזו את התמונות בשמות האלה בדיוק (אותיות קטנות, בלי רווחים):

| שם הקובץ | מה זה | השם הישן במחשב |
|---|---|---|
| `logo.png` | הלוגו (עדיף ריבועי, 512x512) | `logo.png` |
| `background.png` | תמונת הרקע של האתר | `עמדת סלפי_1.png` |
| `event-1.webp` | תמונה 1 בגלריה | `עמדת צילום _2.webp` |
| `event-2.png` | תמונה 2 בגלריה | `עמדת סלפי_1 (2).png` |
| `event-3.png` | תמונה 3 בגלריה (מומלץ תמונה שונה מ-2) | `עמדת סלפי_1 (2).png` |
| `event-4.png` | תמונה 4 בגלריה | `עמדת צילום.png` |
| `og-image.jpg` | תמונה שתופיע כששולחים את הקישור בוואטסאפ/פייסבוק (1200x630) | חדש |

טיפ: לפני ההעלאה כדאי לכווץ את התמונות ב-https://squoosh.app (עדיף פורמט WebP, עד ~200KB לתמונה) – האתר ייטען מהר יותר וגוגל אוהב אתרים מהירים.
אם תמונה חסרה – האתר לא ייראה שבור, היא פשוט לא תוצג.
