# כוח צל

משחק יריות בגוף ראשון לשחקן יחיד, בדפדפן. אתה מפקד צוות של ארבעה לוחמים (צלף, חובש, מקלען, נ״ט) בכפר חוף עם מחבלים, שריון, מסוקים, מטוסים וספינות טילים.

## הפעלה

פותחים את `index.html` בדפדפן מחשב (Chrome / Edge / Firefox). אין צורך בהתקנה או בשרת.
Three.js נטען מ־cdnjs, ואם אין אינטרנט נטען העותק המקומי שב־`vendor/`.

## מבנה

| קובץ | תפקיד |
| --- | --- |
| `index.html` | קנבס, HUD, תפריטים |
| `styles.css` | עיצוב HUD ותפריטים |
| `js/Engine.js` | רנדרר, פוסט־פרוססינג HDR (bloom, עומק שדה בכוונת, כוונת טלסקופית), התנגשויות, חלקיקים ואפקטים |
| `js/Audio.js` | סאונד סינתטי, הד מרחבי, שמע מרחבי, קריאות קשר קוליות |
| `js/Models.js` | דמות לוחם מונפשת (glTF), IK לאחיזת נשק וכריעה, ידיים בגוף ראשון |
| `js/World.js` | הכפר, הבסיס, הים והספינות, מחסות ונקודות חיפוי |
| `js/Actors.js` | מודלי לוחמים ומחלקת בסיס לבינה מלאכותית |
| `js/SquadAI.js` | הצוות שלך ופקודות |
| `js/EnemyAI.js` | התנהגות מחבלים: מחסה, איגוף, רימונים, תגבורת, גגות |
| `js/Player.js` | תנועה: ספרינט, כריעה, שכיבה, החלקה, דילוג מכשולים |
| `js/WeaponSystem.js` | נשקים, בליסטיקה, רתע, טעינה, רימונים, C4 |
| `js/BattlefieldManager.js` | טנקים, נגמ״שים, מסוקים, מטוסים, ספינות, פיצוצים, רצפי הריגה |
| `js/HUD.js` | ממשק: מכ״ם, מצפן, כרטיסי צוות, פיד הריגות |
| `js/Missions.js` | מבצעים ומצב הישרדות |
| `js/Main.js` | תפריט, קלט, לולאה ראשית |

## נכסים

`assets/soldier.glb.js` — דמות Soldier מתוך דוגמאות three.js (MIT), מוטמעת כקובץ JS כדי לעבוד גם מפתיחה מקומית.
`assets/waternormals.js` — מפת נורמלים למים מאותו מקור.

## שליטה
